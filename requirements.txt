# sentence-transformers + faiss + the prebuilt index are present, it upgrades to
# semantic retrieval automatically (see src/rag/rag.py).
#
# Exact pins: must match the committed model artifacts (.keras saved with TF 2.21;
# .joblib / SHAP explainer pickled with scikit-learn 1.9 / shap 0.52).
